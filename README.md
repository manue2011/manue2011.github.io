# Manuel Zárate · Portafolio

Portafolio con temática arcade: proyectos como "misiones", ficha de personaje y una **Zona Arcade** con 5 juegos mentales (Secuencia, Parejas Dev, Descifra el código, Cálculo rápido y Apaga las luces).

HTML, CSS y JavaScript puro, sin dependencias ni compilación. Publicado con GitHub Pages en https://manue2011.github.io

- Proyectos: `js/data.js`
- Juegos: `js/games.js`
- Lógica de la página: `js/main.js`
