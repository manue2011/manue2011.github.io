# Manuel Zárate · Portafolio

Portafolio con dos caras:

- **Modo profesional** (por defecto): diseño futurista con fondo de red de nodos, perfil Dev + RRHH, proyectos y contacto.
- **Game Mode**: el botón de la cabecera transforma la web en un arcade retro, con proyectos como "misiones" y una **Zona Arcade** con 5 juegos mentales (Secuencia, Parejas Dev, Descifra el código, Cálculo rápido y Apaga las luces). Enlace directo: https://manue2011.github.io/?mode=game

HTML, CSS y JavaScript puro, sin dependencias ni compilación. Publicado con GitHub Pages en https://manue2011.github.io

- Proyectos, competencias y contacto: `js/data.js`
- Juegos: `js/games.js`
- Lógica de la página: `js/main.js`
